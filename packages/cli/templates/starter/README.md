# Kawaijs starter template

Copied by `kawa create <name>`. Same showcase script as `examples/hello-world`:

- Scene fades
- Cherry blossom / fog / tint VFX
- Sprite transitions (`bounce`, `dissolve`, `nod`)
- Music, SFX, camera, CG gallery unlocks
- Default `favicon.svg` + SEO fields in `kawa.config.json` (override with your brand)

Keep this folder in sync with the hello-world example when updating the guided demo.
