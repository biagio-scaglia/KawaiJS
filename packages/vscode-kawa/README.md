# Kawaijs Language Support (VS Code Extension)

Rich language support and syntax highlighting for **Kawaijs** (`.kawa`) visual novel scripts.

## Features

- ✨ **Syntax Highlighting**: Full grammar highlighting for `character`, `label`, `scene`, `show`, `hide`, `with`, `menu`, `jump`, `play`, `stop`, `if`, `elif`, `else`, `set`, and dialogue statements.
- 🎨 **Rich Text Tag Support**: Highlighting for inline tags `{b}`, `{i}`, `{color=#...}`, `{size=...}`.
- 💬 **Code Snippets**: Quick scaffolding for characters, labels, choice menus, scenes, and audio controls.
- 🔧 **Auto-Closing & Indentation**: Smart bracket matching and automatic 4-space indentation for blocks.
