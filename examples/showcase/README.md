# After the Bell

A short narrative showcase for **Kawaijs** — not a syntax tour.

Two friends. One envelope. A club that might not survive tomorrow.

## Play

From the monorepo root:

```bash
npm run dev:showcase
```

Or:

```bash
npx kawa dev ./examples/showcase
```

Production build:

```bash
npm run build:showcase
```

Deployed demo (when Pages is refreshed): `https://biagio-scaglia.github.io/KawaiJS/showcase/`

## What's inside

- 2 characters (Yumia & Kaori)
- 3 backgrounds + CG
- Music / SFX hooks
- Branching choices → multiple endings
- Full VN chrome (save, load, rollback, backlog)
